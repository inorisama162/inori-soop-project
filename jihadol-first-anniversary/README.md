# 지하아이돌 방송 1주년 사이트

정적 사이트입니다. 메인 `#/`, 지하돌 첫인상표 `#/impressions`, 스트리머 유형 테스트 `#/quiz`로 구성됩니다.

## 편집할 설정

`config.js`가 멤버 정보, 프로필 사진 경로, 생일, 데뷔일, 방송국 링크, 테스트 문항, 결과 설명, 카페 링크, 카운트 목표와 메인 슬라이드 쇼를 관리합니다.

- 표기: JIHAIDOL, 이니셜 G. 멤버 약칭: 코 / 앵 / 뿡 / 마.
- 제공된 프로필은 `assets/members/`에 멤버 ID로 연결했습니다. PNG를 무손실 WebP로 변환했으며 픽셀과 해상도는 동일합니다. 메인 프로필, 첫인상표, 테스트 시작·결과 화면 및 두 PNG 저장 기능에서 사용합니다.
- 카페 링크: `cafeLinks.impressions`와 `cafeLinks.quiz`를 각각 변경할 수 있습니다. 현재 둘 다 https://cafe.naver.com/jihaidol 입니다. 버튼은 새 창으로 카페를 열며 자동으로 게시하지 않습니다.
- 기념 카운트: `anniversary.crewDays=365`, `auditionDays=1346`은 사용자가 요청한 고정 기념 숫자입니다. 실제 날짜에 따라 증가하는 값이 아닙니다. 숫자는 각각 1.7초 / 3.4초에 도달하며 동작 줄이기 환경에서는 바로 최종 값을 표시합니다.
- 메인 사진: 제공된 7장을 `assets/memories/`에 보관합니다. PNG 6장은 무손실 WebP로 변환하고 JPG 1장은 그대로 유지합니다. `slideshow.photos` 배열이 사진 순서와 대체 텍스트를, `slideshow.interval`이 전환 간격(현재 6.5초)을 관리합니다. 사진은 `object-fit: contain`으로 원본 비율을 유지하고 잘리지 않게 표시합니다. 1.6초 페이드, 이전·다음·일시정지 버튼을 지원하며, 동작 줄이기 환경에서는 자동 재생과 페이드가 꺼집니다. 탭이 숨겨지면 타이머가 멈추고 다른 페이지로 이동하면 정리됩니다.
- 색상과 반응형 배치는 `styles.css`에서 변경합니다.

## 지하돌 첫인상표

네 명에게 각 두 칸씩 총 여덟 이미지를 브라우저 안에서 처리합니다. 서버에 업로드하지 않습니다. 페이지 내 이동 시 유지되지만 새로고침하면 지워집니다. 이미지는 최대 1,400px로 정규화하고 GIF는 한 프레임만 사용합니다. 전체 보기 / 꽉 채우기, 교체, 삭제, 닉네임을 지원합니다. 결과는 1,800×1,250 PNG로 내보냅니다.

## 스트리머 유형 테스트

총 16문항입니다. 사용자가 작성한 1~17번에서 원래 10번을 제외하고, 화면에서는 1~16번으로 순서대로 표시합니다. `sourceNumber`는 원래 번호를 보존합니다.

선택 값 1~5에서 1을 뺀 0~4점을 문항의 `targets`에 포함된 모든 멤버에게 각각 더합니다. 코코미와 뿡치는 7문항으로 원점수 만점 28점, 우앵두와 이노리는 6문항으로 원점수 만점 24점입니다. 최종 비교는 `획득 점수 ÷ 멤버별 만점 × 100`으로 하고, 결과에는 소수 첫째 자리까지 표시합니다. 순위와 동점은 반올림 전 원점수 비율로 계산합니다. 최고점이 같은 멤버는 모두 공동 결과입니다.

결과 설명과 태그도 현재 문항에 맞췄으며, 결과 화면의 상단 강조 상자와 1,200×1,840 PNG 저장 이미지에 다음 안내를 함께 넣었습니다.

> 이 테스트는 지하아이돌 멤버 이노리가 멤버들의 컨펌을 받지 않고 제작했으므로, 극히 주관적일 수 있습니다. 실제 방송 취향 혹은 최애 스트리머와는 무관합니다.


## 검증

메인 슬라이드 쇼의 7장 사진의 동일한 픽셀·해상도와 순서, 자동 순환, 이전·다음, 일시정지·재생, 탭 숨김, 동작 줄이기, 이미지 로딩 대기·실패 처리와 페이지 이동 시 타이머·이벤트 정리를 모의 DOM으로 검증했습니다.

정적 자바스크립트 문법, 자산 참조, 페이지 이동, 요청된 문구 및 프로필 링크, 카운트 시간 차이와 동작 줄이기, PNG 입력과 두 종류 출력, 16문항 전체 진행과 공동 배점, 만점이 다른 멤버의 점수 환산, 답변 수정과 재시작, 네 멤버 단독 결과, 공동 결과, 잘못된 입력 처리 등을 실행해 확인했습니다.

현재 실행 환경에서 정적 사이트용 지원 브라우저 미리보기와 실제 WebMCP 지원 컨텍스트가 제공되지 않아 실제 화면 및 기기별 다운로드 검증은 하지 않았습니다. WebMCP와 UI가 공유하는 동작은 모의 DOM에서 실행해 확인했습니다.
